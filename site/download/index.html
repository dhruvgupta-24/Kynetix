How to install

  1. Tap Download for Android above on your phone. Your browser saves the file (it ends in .apk).
  2. Open the downloaded file from the notification or your Downloads.
  3. Android asks to allow installing apps from your browser. Tap Settings, switch on Allow from this source, then go back.
  4. Tap Install. When it finishes, tap Open and sign in.
  5. If Play Protect warns that the app isn't from Play yet, tap More details and then Install anyway, but only for a file you downloaded from this page.

Done? You can switch Allow from this source back off for your browser in Settings.

Which build do I need?

Almost every phone from the last several years needs the arm64 build, the big button. Pick the armv7 build only for an older or very low-cost phone where the arm64 file says "App not installed". Not sure? Try arm64 first; it won't harm anything if it doesn't fit.

Check the file (optional)

Each build has a SHA-256 checksum. If the checksum of the file you downloaded matches, it is exactly the file we published.

arm64 d1d7503ed9822b2b07307979b3232c78fa0839346956f99924d8282a0def1a86

armv7 a9098c7bfa5c0757fc7e6ee2021ac7cc2e5ee7242b20e3a232abfef43274c32b

On a computer: certutil -hashfile file.apk SHA256 (Windows) or shasum -a 256 file.apk (Mac and Linux). The full list is in SHA256SUMS.txt on the release page.

Is this safe?

Who made this file?

Kynetix, built and signed by Dhruv Gupta. It's the same app that's going to Google Play, signed with the same key, so it can update in place later.

Why does Android warn me?

Android warns about any app installed from outside an app store. That's a sensible default, not a sign something is wrong. Only install files from this page, and check the SHA-256 if you want to be sure.

What does the app do with my data?

No ads, no selling data and no third-party trackers. Everything is explained in plain words in the privacy policy, and you can delete your account and data from inside the app.

Does it cost anything?

No. Kynetix is free during early access.
